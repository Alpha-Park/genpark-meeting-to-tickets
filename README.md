# GenPark Meeting to Tickets

Replicates expensive enterprise B2B meeting bots with a single open-source script. 

**GenPark Meeting to Tickets** takes a messy Zoom, Teams, or Lark transcript and outputs a clean Product Requirements Document (PRD) along with a batch of ready-to-import Jira or Linear tickets in structured JSON.

## Usage
```bash
openclaw use genpark-meeting-to-tickets --transcript "zoom_sync.txt"
```
